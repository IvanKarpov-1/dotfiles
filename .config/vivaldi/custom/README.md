## Adding Style to Vivaldi (CSS)
* Open
    1. **`vivaldi://experiments`**
    or
    2. **`chrome://flags/#vivaldi-css-mods`**

* Enable **"Allow for using CSS modifications"**.
* Open **Appearance** section in settings.
* Under **"Custom UI Modifications"** choose `~/.config/vivaldi/custom` folder.
* ***IMPORTANT:** The CSS files can't have spaces in the filename or they won't work. (in case you want to change it)*
* The theme will have an effect on the next restart of Vivaldi.
